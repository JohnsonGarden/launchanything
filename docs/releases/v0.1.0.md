# LaunchAnything v0.1.0 — macOS Apple Silicon / M 系列

**未签名开发预览 / Unsigned developer preview. DO NOT PUBLISH AS A STABLE PUBLIC RELEASE.**

## 简体中文

这是首次 macOS Apple Silicon Release 草稿，包含经过 macOS CI 检查的 React + Tauri 桌面启动台。

- 每个 APP 独立设置 HTTP / SOCKS5 代理地址与端口
- 环境变量、Chromium 参数、组合模式
- Swift/AppKit 原生应用启动、TCP 端口可达检测
- 玫瑰粉色系、简体中文 / English 切换
- 纯本地配置，不修改系统代理

**本草稿中的 DMG / ZIP 未签名、未经过 Apple 公证。** 仅供开发者审核构建工件，不建议普通用户下载安装或绕过 Gatekeeper。公开正式版必须先完成 Developer ID 签名、Apple 公证、真实设备全新安装与启动测试。Intel / Windows 构建属于其他开发分支，不包含在这次 Apple Silicon Release 中。

## English

This is the first draft macOS Apple Silicon distribution, built and checked using GitHub Actions.

- Per-app HTTP and SOCKS5 proxy profiles and launch modes
- Swift/AppKit native process launching, TCP listener availability checks
- Rose-themed bilingual UI
- Local-only configuration with no system-wide proxy changes

**The DMG and ZIP in this draft are unsigned and not Apple-notarized.** They are for maintainer/build verification only, not a general public release. Before publication, complete Apple Developer ID signing, Apple notarization and a fresh-device install/startup smoke test. Intel and Windows previews are separate and are **not** included in this arm64 release.

### SHA-256

See the attached `SHA256SUMS.txt`, generated from the attached DMG and app ZIP by the same CI workflow.

### Security boundaries

LaunchAnything configures application startup proxy settings; it is not a VPN or transparent all-traffic proxy. Successful TCP checks and application launch do not prove that all traffic is proxied.
